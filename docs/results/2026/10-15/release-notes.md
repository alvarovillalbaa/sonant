# Sonant 0.1.0

A little sound. A lot more feeling.

- 32 semantic interaction and agent cues, with three original sound characters.
- React hooks, scoped playback policy, bounded operations, preferences, and local traces.
- Copy-in CLI, editable recipes, shared kit builder, and portable WAV export with provenance.
- Searchable sound playground, interaction examples, Devtools, and documentation.
- 25 package/runtime checks and 40 browser checks passed in the linked release evidence.

[Website](https://alvarovillalbaa.github.io/sonant/) · [Create a kit](https://alvarovillalbaa.github.io/sonant/#/create) · [Evidence](https://github.com/alvarovillalbaa/sonant/blob/main/docs/results/2026/10-15/initial-release.md)

The attached npm tarball is the reviewed distribution. Registry publication is pending operator execution because the agent's execution environment cannot reach npm's publish endpoint. Until then, the tarball can be installed with npm directly from this release.

```sh
npm install https://github.com/alvarovillalbaa/sonant/releases/download/v0.1.0/alvarovillalbaa-sonant-0.1.0.tgz
```
